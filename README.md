# agent-kit

A personal, reusable kit of AI-agent tooling — skills, commands, and later subagents — portable across Cursor, Claude Code, Codex, and other agents supported by the skills CLI. Built for daily personal use first, public because it may help others.

## Install

The skills CLI installs skills directly from GitHub and detects which agent you are using. Commands are not covered by the CLI, so those are a manual copy.

| Artifact | Install |
| -------- | ------- |
| `source` skill | `npx skills add manu-kaushik/agent-kit --skill source` |
| `commit-message` command | manual copy to your agent's commands directory |

Manual copy paths (when not using the CLI):

| Agent family | Skill path | Command path |
| ------------ | ---------- | ------------ |
| Cursor | `~/.cursor/skills/source/` | `~/.cursor/commands/` |
| Claude Code | `~/.claude/skills/source/` | `~/.claude/commands/` |
| Codex and others | your agent's skills directory | your agent's commands directory |

Copy `skills/source/` for the skill and `commands/commit-message.md` for the command. The skills CLI handles install paths for Cursor, Claude Code, Codex, Amp, Cline, and other supported agents automatically.

## The `source` skill

SOURCE.md is the **persistent project record** — stack, architecture, decisions, deferrals, focus. Chats are temporary; SOURCE.md is not. Any agent in any chat reads it first and updates it when project truth changes.

The skill creates and maintains three files in the target project:

| File | Role | Scope |
| ---- | ---- | ----- |
| `SOURCE.md` | **Required** — the whole project on disk | always |
| `AGENTS.md` | Agent workflow; enforces SOURCE-first behavior | `agents`, `all`; bare `/source` in Cursor, Codex, etc. |
| `CLAUDE.md` | Claude Code guidance; imports SOURCE via `@SOURCE.md` | `claude`, `all`; bare `/source` in Claude Code |

SOURCE.md is always included. Bare `/source` detects the running tool and writes the matching guidance file. Explicit scope overrides detection:

| Invocation | Creates in project root |
| ---------- | ----------------------- |
| `/source` | `SOURCE.md` + guidance file for the running tool |
| `/source agents` | `SOURCE.md`, `AGENTS.md` |
| `/source claude` | `SOURCE.md`, `CLAUDE.md` |
| `/source all` | `SOURCE.md`, `AGENTS.md`, `CLAUDE.md` |

Re-runs are safe. They bootstrap facts from the repository (even in an empty chat), merge durable knowledge from the current conversation when present, and prepend SOURCE pointers without erasing existing content. During normal work, agents update SOURCE.md whenever project facts change — not only when `/source` runs.

This repository's own [SOURCE.md](SOURCE.md), [AGENTS.md](AGENTS.md), and [CLAUDE.md](CLAUDE.md) were generated by running `/source` here.

### Scope is not install location

Two independent axes — easy to conflate:

| Axis | Controlled by | Effect |
| ---- | ------------- | ------ |
| Default guidance file | Running tool — detected on bare `/source` | Cursor, Codex, etc. → `AGENTS.md`; Claude Code → `CLAUDE.md` |
| Override | Explicit scope — `/source agents`, `/source claude`, `/source all` | Which guidance file(s) appear, regardless of detection |

Bare `/source` in Claude Code writes `CLAUDE.md` only — not both files. Use `/source all` when the repo is shared across tool families, or `/source claude` from Cursor to create `CLAUDE.md` for a teammate without switching tools.

## The `commit-message` command

`/commit-message` generates a Conventional Commits message for the currently staged changes and prints it in a fenced code block. It never runs `git commit` or any other write command — reviewing and committing stay with you.

If nothing is staged, it says so and stops.

## Skill vs subagent vs command

The deciding constraint is that **a subagent gets a fresh context window and only sees the prompt the parent hands it** — it cannot read the current conversation. Everything else follows from that.

| Artifact | Use when | Examples |
| -------- | -------- | -------- |
| Skill | Needs conversation context; injects knowledge or procedure into the main window | `source` — records decisions from the current chat |
| Subagent | Reads a lot, writes a little; the value is keeping that reading out of the main context | code review, issue triage, research |
| Command | Explicit user trigger, short deterministic procedure | `commit-message` |

## Layout

```
agent-kit/
├── skills/
│   └── source/
│       ├── SKILL.md
│       └── templates/
└── commands/
    └── commit-message.md
```

`skills/` at root is the standard container directory for the skills CLI, so discovery stops there. The CLI only matches files literally named `SKILL.md`, so `commands/*.md` is invisible to it — and the same will hold for `agents/*.md` when subagents land.
